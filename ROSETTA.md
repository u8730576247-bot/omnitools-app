# The Rosetta Principle

KillKit is not a collection of applications.

KillKit is a translation engine.

Everything we build transforms one representation into another while preserving or enriching meaning.

Every application is a translator.

Every translator belongs to a constellation.

Every constellation belongs to the same universe.

- Voice
- Text
- Image
- Video
- Audio
- PDF
- Document

- Metadata
- Database
- Knowledge Graph

# Translation

Every application answers four questions.

## INPUT

What enters the system?

## TRANSFORMATION

What changes?

## OUTPUT

What leaves the system?

## MEANING

Why is the output more valuable than the input?

# Shared Engines

A transformation should never be implemented twice.

Common engines include:

- OCR
- Speech Recognition
- AI
- Translation
- Embeddings
- Metadata
- PDF Engine
- Image Engine
- Security Engine
- Knowledge Graph

Applications reuse engines.

They do not duplicate them.

Each constellation contains many gemstones.

---

# Gemstones

A gemstone is an individual capability.

Examples:

- Merge PDF
- OCR
- Compress Image
- Invoice Generator
- EXIF Cleaner
- VOX
- JSON Converter

Every gemstone should:

- solve one problem well;
- integrate naturally with other gemstones;
- be reusable;
- preserve meaning.
